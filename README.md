# Trabalho-de-Desenvolvimento-de-Front-End
Trabalho de Desenvolvimento de Front-End sobre a criação de um site funcional seguindo os requisitos do guia entregue pelo professor Welington Soares (Docca).
#
# Inicio do trabalho
## 23/10/2026
Base do trabalho será um site de ong para adoção de cachorros (link [https://adotar.com.br/]), escolhemos essa opção pois ela conclui os requisitos de forma completa e simples. Usamos o Draw.io para a prototipagem da interface do nosso site, separamos os seguintes blocos: 
- banner
- navegação
- aside
- área principal (grid)
- carrossel de imagens
- tabela 7x5
- cards de feiras virtuais
- galeria de imagens
- formulario (verificavel)
- FAQ
- opções
Por enquanto essa é a primeira versão do protótipo, mais itens serão adicionados caso seja necessário.
