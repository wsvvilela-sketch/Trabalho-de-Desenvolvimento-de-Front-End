# Trabalho-de-Desenvolvimento-de-Front-End
Trabalho de Desenvolvimento de Front-End sobre a criação de um site funcional seguindo os requisitos do guia entregue pelo professor Welington Soares (Docca).
#
# Inicio do trabalho
## 23/10/2026
Base do trabalho será um site de ong para adoção de cachorros (link [https://adotar.com.br/]), escolhemos essa opção pois ela conclui os requisitos de forma completa e simples. Usamos o Draw.io para a prototipagem da interface do nosso site, separamos os seguintes blocos: 
- banner
- navegação
- aside
- área principal (grid)
- carrossel de imagens
- tabela 7x5
- cards de feiras virtuais
- galeria de imagens
- formulario (verificavel)
- FAQ
- opções

Por enquanto essa é a primeira versão do protótipo, mais itens serão adicionados caso seja necessário.
# Finalização do Protótipo
## 27/10/2026
Adicionamos novas áreas no protótipo para completar alguns requisitos do guia, sendo eles o sistema de abas e os 2 formulários, também corrigimos a função da área de FAQ que não usa um sistema de abas mas sim de accordion e a galeria de imagens usar o sistema de grid para completar o requisito de 2 grids em casos diferentes.
Mudanças feitas:
- Adição da área de abas (Sobre, Serviços, Contato, Locais, Representantes, Selos de credibilidade);
- Adição do formulário HTML (Nome completo, E-mail, Telefone, Cidade);
- Adição do formulário JavaScript (Nome completo, E-mail, Telefone, Cidade, Sua Idade ,Tipo de residência, Tem outros animais?, Já cuidou de cães?);
- Correção da função da área FAQ;
- Galeria de imagens usará o sistema grid.
